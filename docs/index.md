# ESP32-DATV-SA

Stand-alone DVB-S2 transmitter on an ESP32-C3. *Bağımsız ESP32-C3 DVB-S2 vericisi.*

## [Video converter / Video dönüştürücü →](converter/)

**<https://barisdinc.github.io/ESP32-DATV-SA/converter/>**

Turn any video file into the transmitter's `video.bin` in your web browser, nothing to install.
*Herhangi bir video dosyasını tarayıcınızda, hiçbir şey kurmadan vericinin `video.bin` dosyasına çevirin.*
